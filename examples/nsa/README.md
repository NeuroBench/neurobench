# Neuromorphic Sequential Arena (NSA) baselines

Examples that run baselines from the
[Neuromorphic Sequential Arena](https://arxiv.org/abs/2505.22035) (Ma et al., IJCAI
2025) through NeuroBench, following up
[issue #264](https://github.com/NeuroBench/neurobench/issues/264).

## What NSA is

NSA is a benchmark suite for temporal processing with spiking neural networks. It
collects seven real-world sequence tasks, each with its own dataset and timescale, and
reports a common set of spiking baselines on all of them, covering task accuracy,
training speed, memory use and energy cost. The code and models live in the
[`neuroseqbench`](https://github.com/liyc5929/neuroseqbench) package, and NSA hosts
preprocessed copies of every dataset on
[Hugging Face](https://huggingface.co/datasets/liyc5929/neuroseqbench/tree/main/neuromorphic_sequential_arena)
so that results are reproducible.

NSA already supports NeuroBench metrics inside its own training scripts (the
`--use-neurobench-metrics` flag). These examples go the other way: they run NSA's
baselines inside the NeuroBench harness, using NeuroBench's `Benchmark`, metrics and
model wrappers, so the numbers line up with the rest of the NeuroBench examples.

## Tasks and datasets

NSA has seven tasks. NSA's own NeuroBench integration covers four of them (AL, HAR,
EEG-MI, SSL), and those four are the scope of this port.

| Task | Dataset | Source | Readout | Status here |
| --- | --- | --- | --- | --- |
| Human Activity Recognition (HAR) | WISDM, smartwatch gyroscope | [Weiss, 2019](https://archive.ics.uci.edu/dataset/507/wisdm+smartphone+and+smartwatch+activity+and+biometrics+dataset) | mean over time | [`har/`](har/), LIF feedforward and recurrent |
| Autonomous Localization (AL) | synthetic AL dataset generated by NSA | NSA | mean over time | planned |
| EEG Motor Imagery (EEG-MI) | OpenBMI | [Lee et al., GigaDB](https://gigadb.org/dataset/100542) | last time step | planned |
| Sound Source Localization (SSL) | SLoClas, with added noise | [SLoClas](https://zenodo.org/records/5211296) | mean over time | planned |
| Automatic Lip-Reading (ALR) | DVS-Lip (event camera) | [Tan et al., 2022](https://ieeexplore.ieee.org/document/9879993) | | out of scope |
| Audio Denoising (AD) | Intel N-DNS | [Timcheck et al., 2023](https://iopscience.iop.org/article/10.1088/2634-4386/ace737) | | out of scope |
| Automatic Speech Recognition (ASR) | AISHELL-1 | [Bu et al., 2017](https://arxiv.org/abs/1709.05522) | | out of scope |

For every task, the example downloads NSA's preprocessed split rather than redoing the
preprocessing, so accuracies stay comparable with the NSA paper. Dataset loading is kept
inside each task folder (for example `har/data.py`) because the data is curated by NSA,
not by NeuroBench.

## Baseline networks

NSA reports the same family of baselines on each task. They fall into three groups:

| Group | Baselines |
| --- | --- |
| Feedforward spiking neurons | LIF, CELIF, LTC, SPSN, PMSN |
| Recurrent spiking neurons | LIF, CELIF, LTC (with recurrent weights) |
| Spiking architectures | Gated Spiking Neuron (GSN), SpikingTCN, Spike-Driven Transformer, binary SSM, GSU SSM |

The neuron models and architectures all come from `neuroseqbench`
(`neuroseqbench.network.neuron` and `neuroseqbench.network.structure`). Hyperparameters
for each run are in NSA's `experiments/neuromorphic_sequential_arena/<TASK>/run_all.sh`.

This port starts with the LIF baselines, feedforward and recurrent, since LIF is the
reference neuron for NeuroBench and the simplest to check against the paper. The other
neurons and architectures can be added later through the same wrapper.

## Shared helpers

`nsa_common.py` holds the glue every task uses:

- `TimeFirstWrapper` turns NeuroBench's batch-first `[B, T, C]` input into NSA's
  time-first `[T, B, C]`, and applies NSA's readout (mean over time, or the last step for
  EEG-MI).
- `wrap_for_neurobench` wraps the network as a `TorchModel` and registers NSA's
  `SpikeGeneration` modules as activations, so ActivationSparsity and
  SynapticOperations see the spikes.

## Dependencies

`neuroseqbench` is an external dependency and is not added to NeuroBench's
`pyproject.toml`. Install it separately to run these examples:

```
pip install git+https://github.com/liyc5929/neuroseqbench.git
```

## Tests

`tests/test_nsa_examples.py` covers the wrapper, hook detection and the metric values.
It is skipped when `neuroseqbench` is not installed, so it does not run in CI.
